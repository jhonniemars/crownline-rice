# 🌾 Grace Harvest Rice Trading — Dashboard

A responsive admin dashboard UI for a rice trading business:
stock overview, sales, installments (utang/balance), customers,
suppliers, delivery and reports.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript (zero dependencies)
- Deploy-ready for **GitHub Pages**

## Run Locally
```bash
git clone https://github.com/YOUR-USERNAME/grace-harvest-dashboard.git
cd grace-harvest-dashboard
# just open index.html in a browser
